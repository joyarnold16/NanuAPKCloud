# Nanu God UI v3 APK Source

All-in-one native Android APK source. No Termux engine needed after install.

## v3 UI fixes
- Safe top padding below Android status bar.
- Cleaner header; no text touches battery/signal area.
- Settings button opens Security screen.
- Mode change moved to Security with large Paper/Demo/Testnet/Live buttons.
- Live mode requires typing UNLOCK LIVE.
- Bigger fonts and less cramped cards.
- Signal cards and metrics have corrected spacing.
- Nanu face responds to P&L: calm/smile/big smile/sad/crying.

## Build
Push this source to GitHub and run Build Nanu God UI V3 APK.
The APK is uploaded as a GitHub Release named nanu-god-ui-v3.
